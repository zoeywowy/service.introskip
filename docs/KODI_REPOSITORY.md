# Kodi repository

The Kodi repository is maintained separately from the IntroSkip service source:

- **Repository and package feed:** [zoeywowy/repository.introskip](https://github.com/zoeywowy/repository.introskip)
- **Service source and direct-install releases:** [zoeywowy/service.introskip](https://github.com/zoeywowy/service.introskip)

Install the repository using Kodi's **Settings → File manager → Add source** and this address:

`https://zoeywowy.github.io/repository.introskip/`

Then select **Add-ons → Install from zip file → IntroSkip Repository** and install the repository ZIP Kodi lists. Install IntroSkip from **Install from repository → IntroSkip Repository → Services**.

See the repository project's [installation guide](https://github.com/zoeywowy/repository.introskip/blob/main/docs/INSTALLATION.md) for the complete steps and troubleshooting.
