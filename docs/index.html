IntroSkip Kodi Repository

For Kodi 22, download and install the repository ZIP:

repository.introskip-1.0.3.zip

In Kodi: Add-ons → Install from zip file → select the downloaded ZIP.

Repository data (Kodi standard layout)

  • Add-on index (addons.xml)
  • MD5 checksum (addons.xml.md5)
  • Package directory base
