IntroSkip Kodi Repository

For Kodi 22: Add source https://zoeywowy.github.io/service.introskip/, then Add-ons → Install from zip file and choose the repository ZIP.

Repository installer

  • repository.introskip-1.0.0.zip
  • service.introskip-0.0.23.zip (direct installation)

Once installed, find IntroSkip Repository under Add-ons → Install from repository and choose IntroSkip.
